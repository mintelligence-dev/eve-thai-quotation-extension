# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and considerate, give and accept feedback gracefully, and focus on what is best for
the people who use and build this project. Harassment, insults, personal attacks and publishing other people's
private information are not acceptable, in issues, pull requests or anywhere else the project is discussed.

## Reporting

If you see or experience behaviour that breaks this code, contact the maintainers at M Intelligence through
<https://m-intelligence.tech>. Reports are handled privately. Maintainers may remove comments, close
discussions or block accounts that break this code.
